# 📘 CPP Module 06 — C++ Casts

## Introduction

**CPP06** introduces type casting in C++ and explores the different casting operators available in the language.

This module focuses on type conversion, serialization, scalar conversion, and runtime type identification.

---

# Compilation

```bash
make
```

Run the executable:

```bash
./"program_name"
```

---

# Exercises

## ex00 — Conversion of scalar types

Implementation of a scalar converter capable of converting literals into multiple C++ scalar types.

### Concepts used

* scalar conversion
* type parsing
* static methods
* overflow handling

---

## ex01 — Serialization

Implementation of serialization and deserialization using raw pointers and integer representations.

### Concepts used

* reinterpret_cast
* serialization
* pointer conversion

---

## ex02 — Identify real type

Using runtime type identification to detect the real type of objects through base class pointers and references.

### Concepts used

* dynamic_cast
* polymorphism
* inheritance
* base and derived classes

---

# Project Constraints

* Mandatory standard: **C++98**
* Compilation flags:

```bash
-Wall -Wextra -Werror
```

* Modern C++ features are forbidden.
