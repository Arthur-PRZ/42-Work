# CPP Module 03 — Inheritance

## 📚 Description

**CPP03** introduces inheritance in C++ and explores relationships between classes.

This module focuses on extending classes, reusing existing behavior, and understanding how constructors, destructors, and member functions behave in inheritance hierarchies.

This module covers:

* inheritance
* base and derived classes
* constructor and destructor chaining
* access modifiers
* member function inheritance
* method overriding
* canonical class form
