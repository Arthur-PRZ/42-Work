# 📘 CPP Module 08 — Templated Containers, Iterators & Algorithms

## Introduction

**CPP08** explores the use of templated containers, iterators, and algorithms in C++.

This module focuses on manipulating STL containers, searching data efficiently, and understanding how generic algorithms work.

---

# Compilation

```bash
make
```

Run the executable:

```bash
./"program_name"
```

---

# Exercises

## ex00 — Easy find

Implementation of a generic search function capable of finding values inside STL containers.

### Concepts used

* STL containers
* iterators
* generic algorithms
* templates
* exception handling

---

## ex01 — Span

Creation of a class capable of storing numbers and calculating shortest and longest spans.

### Concepts used

* containers
* algorithms
* sorting
* range calculations
* exception handling

---

## ex02 — Mutated abomination

Implementation of an iterable stack by extending the standard stack container.

### Concepts used

* container adapters
* iterators
* inheritance
* STL containers
* generic programming

---

# Project Constraints

* Mandatory standard: **C++98**
* Compilation flags:

```bash
-Wall -Wextra -Werror
```
