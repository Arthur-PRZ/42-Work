# 📘 CPP Module 07 — C++ Templates

## Introduction

**CPP07** introduces templates in C++ and explores generic programming.

This module focuses on writing reusable and flexible code that can work with multiple data types without duplication.

---

# Compilation

```bash
make
```

Run the executable:

```bash
./"program_name"
```

---

# Exercises

## ex00 — Start with a few functions

Implementation of generic template functions working with multiple types.

### Concepts used

* function templates
* generic functions
* type abstraction
* template instantiation

---

## ex01 — Iter

Creation of a generic iteration function applied to arrays of different types.

### Concepts used

* templates
* iterators
* arrays
* function pointers
* generic programming

---

## ex02 — Array

Implementation of a templated array class with bounds checking and dynamic memory management.

### Concepts used

* class templates
* dynamic allocation
* operator overloading
* exception handling
* generic containers

---

# Project Constraints

* Mandatory standard: **C++98**
* Compilation flags:

```bash
-Wall -Wextra -Werror
```

* Modern C++ features are forbidden.
