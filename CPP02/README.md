# 📘 CPP Module 02 — Ad-hoc Polymorphism, Operator Overloading & Orthodox Canonical Form

## Introduction

**CPP02** introduces fixed-point numbers, operator overloading, and the Orthodox Canonical Form in C++.

This module focuses on writing more complete and reusable classes while learning how operators work internally.

---

# Compilation

```bash
make
```

Run the executable:

```bash
./"program_name"
```

---

# Exercises

## ex00 — My First Class in Orthodox Canonical Form

Implementation of a basic fixed-point number class following the Orthodox Canonical Form.

### Concepts used

* default constructor
* copy constructor
* copy assignment operator
* destructor
* encapsulation

---

## ex01 — Towards a more useful fixed-point number class

Extending the fixed-point class with conversions between integers, floats, and fixed-point values.

### Concepts used

* fixed-point arithmetic
* float conversion
* integer conversion
* member functions
* stream insertion operator

---

## ex02 — Now we’re talking

Adding comparison, arithmetic, and increment/decrement operators to the fixed-point class.

### Concepts used

* operator overloading
* comparison operators
* arithmetic operators
* increment and decrement operators
* static member functions

---

## ex03 — BSP

Implementation of a function determining whether a point is inside a triangle using fixed-point calculations.

### Concepts used

* geometry calculations
* barycentric logic
* fixed-point precision
* immutable objects
* object composition
