# 📘 CPP Module 04 — Subtype Polymorphism, Abstract Classes & Interfaces

## Introduction

**CPP04** introduces subtype polymorphism, abstract classes, and interfaces in C++.

This module focuses on dynamic behavior through inheritance, virtual functions, and abstract designs.
It also explores deep copies and proper memory management in object-oriented programming.

---

# Compilation

```bash
make
```

Run the executable:

```bash
./"program_name"
```

---

# Exercises

## ex00 — Polymorphism

Implementation of animal classes demonstrating polymorphism through virtual functions.

### Concepts used

* inheritance
* virtual functions
* method overriding

---

## ex01 — I don’t want to set the world on fire

Adding Brain objects to animals while implementing deep copies and proper memory management.

### Concepts used

* composition
* deep copy
* dynamic allocation

---

## ex02 — Abstract class

Transforming the Animal class into an abstract base class and using interfaces through pure virtual functions.

### Concepts used

* abstract classes
* pure virtual functions
* interfaces
* dynamic polymorphism
