# 📘 CPP Module 01 — Memory Allocation, References & Pointers

## Description

**CPP01** expands on the basics introduced in CPP00 and focuses on memory management and object manipulation in C++.

---

# Compilation

```bash
make
```

Run the executable:

```bash
./"program_name"
```

---

#  Exercises

## ex00 — BraiiiiiiinnnzzzZ

A simple introduction to heap and stack allocation using zombie objects.

### Concepts used

* stack allocation
* heap allocation
* constructors
* destructors
* object lifetime

---

## ex01 — Moar brainz!

Creating multiple zombie objects dynamically using arrays and memory allocation.

### Concepts used

* dynamic allocation
* arrays of objects
* loops
* memory management
* heap usage

---

## ex02 — HI THIS IS BRAIN

An introduction to pointers and references and the differences between them.

### Concepts used

* pointers
* references
* memory addresses
* dereferencing

---

## ex03 — Unnecessary violence

A small weapon and human interaction system demonstrating references and pointers inside classes.

### Concepts used

* references in classes
* pointers in classes
* object interaction
* encapsulation

---

## ex04 — Sed is for losers

A program that replaces occurrences of a string inside a file without using `sed`.

### Concepts used

* file streams
* string manipulation
* reading and writing files
* search and replace logic

---

## ex05 — Harl 2.0

A complaint system using member functions associated with different log levels.

### Concepts used

* member function pointers
* switch-like logic
* conditional execution
* class methods

---

## ex06 — Harl filter

An extension of the previous exercise with filtering behavior depending on the selected log level.

### Concepts used

* switch statements
* filtering systems
* control flow
* log levels

---

# Project Constraints

* Mandatory standard: **C++98**
* Compilation flags:

```bash
-Wall -Wextra -Werror
```

* Modern C++ features are forbidden.
